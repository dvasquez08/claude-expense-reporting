# Claude Expense Tracker

Hello! Here are the files that you will need to get stared as shown in the YouTube tutorial.
Copy all the files here and follow these steps

## What To Do

1. Download all the files from this repo, or clone them with git.
2. Create a new folder called **Receipts**.
3. Inside the **Receipts** folder, create two new folders called **Inbox** and **Processed**.
4. Move any invoices and receipts that need to tracked, into the **Invoice** folder. When Claude ingests your files, it will move them into **Processed**

This system will create two types of files. A master CSV file where all expenses are tracked.
An Excel document, that is completed for monthly reporting.

No API keys, no additional tools to install. Just plug-and-play and you're ready to go!
